직원 집주소 관리

사용내역을 업로드하면 이용자명이 자동으로 추가됩니다. 집주소를 입력하고 좌표 확인을 누르세요. 집주소는 이 브라우저(localStorage)에만 저장되며 서버로 업로드되지 않습니다(주소→좌표 변환만 카카오 API 사용).

이용자명집주소개별 반경(m)좌표 상태

일괄등록 엑셀 컬럼: 이용자명, 집주소, (선택) 반경. 개별 반경을 비우면 설정 탭의 기본 반경을 씁니다.

카카오 지도 연결

카카오 키 발급 방법
  1. developers.kakao.com → 내 애플리케이션 → 애플리케이션 추가
  2. 앱 → 플랫폼 키 → JavaScript 키 → JavaScript SDK 도메인에 접속 주소 등록 (웹: https://osh7312810-cmd.github.io, 내 PC: http://localhost:8080)
  3. (메뉴가 있으면) 카카오맵 사용 설정 ON
  4. JavaScript 키를 복사해 위에 입력
내 PC에서 쓸 때는 파일을 더블클릭(file://)하지 말고 실행.bat으로 열어주세요.

Gemini AI 연결 (이상징후 요약 · 경영진 보고서)

선택한 모델이 혼잡하거나 종료된 경우 gemini-3.5-flash → flash-latest → flash-lite 순으로 자동 전환합니다.

Gemini 키 발급: Google AI Studio → Get API key → API 키 만들기 → 복사해서 위에 입력.
키는 이 브라우저에만 저장됩니다. AI 기능을 쓸 때 분석 결과 요약 통계와 의심 거래 목록(가맹점명·업종·금액·일시·거리)이 Google로 전송됩니다. 카드번호·사업자번호·집주소는 보내지 않으며, 아래 옵션을 켜면 이용자명도 직원01 형태로 바꿔 보냅니다(결과 화면에서는 실명으로 복원).
