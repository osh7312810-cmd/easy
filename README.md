# 법인카드 집근처 사용 분석

법인카드 사용내역을 직원 집주소와 비교해 **집 근처에서 주말·공휴일·심야에 사용한 거래**를 찾아내는 웹 도구입니다.
카카오 지도로 위치를 확인하고, Gemini AI로 이상징후 요약과 경영진 보고서를 만듭니다.

## 주요 기능
- 카드사 엑셀/CSV 업로드 (순번, 카드번호, 이용자명, 이용일, 가맹점명, 이용금액, 가맹점 주소 … 18개 컬럼)
- 직원 집주소 관리 및 엑셀 일괄등록
- 가맹점 주소 → 좌표 변환 (카카오 지도), 집과의 거리 계산
- 판정: **고위험**(집근처 + 주말·공휴일/심야) · **주의** · **정상** · **제외**(온라인/PG, 해외)
- 지도 표시, 이용자별 요약, 결과 엑셀 다운로드
- Gemini AI 이상징후 요약 · 경영진 보고서 (Word/HTML/인쇄 저장)

## 사용 방법
1. 설정 탭에서 **카카오 JavaScript 키**와 **Gemini API 키**를 입력합니다. 키는 각자의 브라우저에만 저장됩니다.
2. 카카오 개발자 콘솔의 *JavaScript SDK 도메인*에 접속 주소를 등록해야 합니다.
   - 웹 배포 주소: `https://osh7312810-cmd.github.io`
   - 내 PC에서 실행: `http://localhost:8080` (`실행.bat` 더블클릭)
3. 대시보드에서 사용내역 엑셀 업로드 → 직원 집주소 입력 → **집근처 분석 실행**

## 개인정보
- 카드 내역·집주소는 서버로 업로드되지 않고 브라우저 안에서만 처리됩니다.
- 주소→좌표 변환 시 가맹점/집 주소가 카카오로, AI 기능 사용 시 요약 통계와 의심 거래 목록(이용자명 가명 처리 가능)이 Google로 전송됩니다.
- 실제 카드 사용내역 파일은 이 저장소에 올리지 마세요.
